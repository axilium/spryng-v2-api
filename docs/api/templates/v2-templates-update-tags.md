## API overview

This endpoint allows you change the tags associated with a template. Templates can be used to send consistent and personalised messages. TemplateIds can be embedded into the body of a request when sending or scheduling a message in the future.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

Please note. A Template user can only send messages using predefined templates, view the inbox and the sent items but will be unable to create, manage or delete templates or access any other settings and controls. For further information and configuration on user permissions, log into the Spryng portal and proceed to user permissions.

## URL & method

```
https://api.spryng.nl/v2/templates/{templateId}/tags
```

**Method: PATCH**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |
| Content-Type | String | application/json |

**Example request header:**

```
PATCH https://api.spryng.nl/v2/templates/{templateId}/tags
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
-H 'Content-Type: application/json'
```
