## API overview

This endpoint allows you to retrieve data for a single template. Templates can be used to send consistent and personalised messages. TemplateIds can be embedded into the body of a request when sending or scheduling a message in the future.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/templates/{templateId}
```

**Method: GET**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Esendex account reference - e.g. SPNL0000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/templates/{templateId}
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

import java.io.OutputStream;
import java.net.HttpURLConnection;

          try (var reader = new java.io.BufferedReader(

              StringBuilder response = new StringBuilder();
              String line;

              while ((line = reader.readLine()) != null) {
                  response.append(line.trim());
              }
            }
        }
        else {
          try (var errorReader = new java.io.BufferedReader(new java.io.InputStreamReader(connection.getErrorStream(), StandardCharsets.UTF_8))) {
            StringBuilder errorResponse = new StringBuilder();
            String line;

                errorResponse.append(line.trim());

          } catch (Exception e) {

          }
        }
