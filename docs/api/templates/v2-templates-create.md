## API overview

This endpoint allows you to create a single template. Templates can be used to send consistent and personalised messages. TemplateIds can be embedded into the body of a request when sending or scheduling a message in the future to save you time drafting the same message repeatedly.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

Please note. A Template user can only send messages using predefined templates, view the inbox and the sent items but will be unable to create, manage or delete templates or access any other settings and controls. For further information and configuration on user permissions, log into the Spryng portal and proceed to user permissions.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/templates
```

**Method: POST**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |
| Content-Type | String | application/json |

**Example request header:**

```
POST https://api.spryng.nl/v2/templates
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
-H 'Content-Type: application/json'
```

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required, or conditional, request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Description |
| --- | --- | --- |
| name | String | The name of the template |
| templateType | String | The type of the template to be used. Currently available options is "Text" only |
| messageType | String | Used to help ensure that messages are sent in alignment with local regulations. For example Marketing messages during quiet hours. Enum e.g. Unknown \| MarketingAndResearch \| NotificationsAndReminders \| AuthenticationAndSecurity \| PaymentsAndCollections \| InternalOperations \| CustomerSupport \| Conversational \| BlueLight |
| channelSettings | JSON object | Configuration of the settings required for the channel the template is being created for |
| channelSettings.sms | JSON object | Configurations specific for sms templates only |
| content | String | The body of the message for the template |

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Paramter | Type | Description |
| --- | --- | --- |
| channelSettings.sms.characterSet | String | Allowed character sets are: Auto \| GSM \| Unicode. GSM uses a smaller character set which allows characters per message part to around 140. Unicode allows using of a large set of special characters and Unicode emojis but reduces characters per message part to around 70. Auto will detect if Unicode characters are used and default to GSM if not. If omitted the platform will default to “Auto” |

In order to shorten a URL within a message, embed [shorten: http://example/longURL.com] into the request "body.text" property. The platform will then automatically convert your long URL into a shortened URL in format uk.endx.io/abcd123. These are unique per recipient.
To see an example of this request, see the request body examples section below. Please note, the shorten URL capability is not available during Trial. You will need to upgrade to a full account to use this feature.

**Request body example**

```
{
    "name": "Template_999",
    "templateType": "Text",
    "messageType": "MarketingAndResearch",
    "channelSettings": {
        "sms": {
            "characterSet": "Auto"
        }
    },
    "content": "This is a template body [shorten:http://example/longurl.com]"
}
```
