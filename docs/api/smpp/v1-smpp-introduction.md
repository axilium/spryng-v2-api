## What is SMPP

SMPP (Short Message Peer-To-Peer) is an industry-standard protocol which provides an interface for the transfer of SMS messages over the Internet to people globally. It is designed for customers who have existing SMPP connections or who are looking to use software platforms that require an SMPP interface.

With our SMPP API you can send outbound and receive inbound messages across all supported SMS sender types, including; Standard, short code, long code and alphanumeric senderIds. We also support multiple encoding standards, such as; GSM and Unicode (UCS2). Delivery receipts (DLRs) are provided to ensure accurate message status updates in near real-time.

Our Spryng SMPP API is integrated directly with our platforms and services, which are ISO 27001 accredited and use the most secure communication protocols (TLS 1.2*), giving you peace of mind that your data is protected and compliant with highest standards allowing you to maintain trust and improve engagement with your customers. Our systems can manage multiple simultaneous SMPP connections (or binds) per Account, scaling dynamically as required to support demand, allowing you to send high volumes of messages without performance loss.

The below guide outlines how to establish a secure connection and configure your integration with the required SMPP settings.

*TLS 1.2 is our preferred connection protocol, however if you require connection via VPN this can be accommodated.

Please note, we currently support [SMPP v3.4](https://smpp.org/SMPP_v3_4_Issue1_2.pdf) only.

## Glossary

| Term | Description |
| --- | --- |
| SMPP | Short Message Peer-To-Peer protocol |
| PDU | Protocol Data Units |
| DLR | Delivery reports |
| Bind | A request to establish a session or connection for sending one-way or two-way messages |
| MC/SMCC | Message Centre/ SMS Gateway |
| ESME | External Short Message Entity |
| BIND_TRANSMITTER | You send messages on this bind and can opt to receive delivery notifications on another bind |
| BIND_RECEIVER | You receive delivery notifications on this bind |
| BIND_TRANSCEIVER | You both send messages and receive delivery notifications on this bind |
| UNBIND | You wish to close your bind to us |
| ENQUIRE_LINK | You want to ensure your bind stays connected |
| SUBMIT_SM | You are submitting a short message |
| DELIVER_SM | We are sending you a delivery notification or received message |
