## API overview

This endpoint allows you to retrieve a list of all contacts within a group associated with your account in a single API call. The request can be filtered by: groupId, accountReference, destination, metadataKey, Search, pageSize, pageNo, sortOrder and sortBy. This is the ideal tool for synchronizing your contact list from another system, such as a CRM, an e-commerce platform, or a customer database, ensuring your contacts are always up-to-date.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

```
https://api.spryng.nl/v2/groups/{groupId}/contacts
```

**Method: GET**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/groups/{groupId}/contacts
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Optional input path parameters**

The below parameters are optional within the path, they are designed to provide you further capability to filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| GroupId | GUID | Filter by groupIds |
| search | Query | Ability to search using the following: address \| first name \| last name \| quick name. Searching will retrieve information from all parameters |
| destination | Query | Filter contacts by the destination. Value should be a valid ISO3166 country code. For example: GB \| DE \| IT \| US |
| contactOwnership | Query | Specifies the ownership type of a contact to filter by. Possible values: Shared \| Owned \| All. Default value = All |
| sortBy | Query | Sort contacts. Available values: name |
| sortOrder | Query | Sets the sorting direction. Default = descending. Available values: Asc & Desc |
| search | Query | Ability to search using the following: address \| firstName \| lastName \| quickName. Searching will retrieve information from all parameters |
| destination | Query | Filter contacts by the Destination. Value should be a valid ISO3166 country code. For example: GB \| DE \| IT \| US |
| optOutStatus | Query | Filter contacts by the optOutStatus. Allowed values are subscribed or unsubscribed |
