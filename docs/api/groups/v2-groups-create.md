## API overview

This endpoint allows you to create a new group. This is the ideal tool for synchronising your contact list from another system, such as a CRM, an e-commerce platform, or a customer database, ensuring your contacts are always up-to-date.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

        }

            System.err.println("Failed due to error: " + e.getMessage());

        if (responseCode >= 200 && responseCode < 300) {
          try (var reader = new java.io.BufferedReader(

              StringBuilder response = new StringBuilder();

            System.err.println("Failed to read error response: " + e.getMessage());
          }
        }
