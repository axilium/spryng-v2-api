## API overview

This endpoint allows you to delete a single group in a single API call. Deleting a group does not delete the contacts within the group or delete any other groups which the contact may be associated to. This is the perfect tool for maintaining your contact list from another system, such as a CRM, an e-commerce platform, or a customer database, ensuring your contacts are always up-to-date.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

```
https://api.spryng.nl/v2/groups/{groupId}
```

**Method: DELETE**
