## API overview

This endpoint allows you to remove one or more contacts from a single group. Removing contacts from a group does not delete the contact record or the group. A group can still exist with no associated contacts. To delete a group, please refer to the Delete documentation within the Group category. This is the perfect tool for maintaining your contact list from another system, such as a CRM, an e-commerce platform, or a customer database, ensuring your contacts are always up-to-date.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

```
https://api.spryng.nl/v2/groups/{groupId}/contacts?contactId={contactId}
```

**Method: DELETE**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |

**Example request header:**

```
DELETE https://api.spryng.nl/v2/groups/{groupId}/contacts?contactId={contactId}
-H 'Api-Key: YOUR_API_KEY'
```

**Required query parameters**

| Property | Type | Description |
| --- | --- | --- |
| contactId | GUID | One or more contacts to be deleted from a single group. contactIds must be provided as a GUID within the path. If more than one contact is being removed provide contactIds as an array |
