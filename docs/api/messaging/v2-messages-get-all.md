# Messaging / Get all

## API overview

This endpoint returns all outbound and inbound messages associated with your account. This can be filtered based on channel, message type, status, userId and more.

 Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/messages
```

**Method: GET**

## Headers & parameters

These parameters are mandatory and must be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Description |
| --- | --- |
| X-Api-Key | API Key value |
| AccountReference | Your Spryng Account reference - e.g. SPNL0000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/messages
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Query parameters**

The below parameters are available as optional filters to your request. They should be provided as a query within the request path.

| Property | Type | Description |
| --- | --- | --- |
| accountReference | Array | The list of account references provided as an array |
| requestId | GUID | Will filter to requestIds provided for the request |
| conversationId | GUID | Will show all inbound and outbound messages belonging to a conversation. A conversation is unique by account-recipient and will contain all messages to and from a recipient in an account |
| status | String | Status of the requested message(s). Enum e.g. Delivered \| Received \| Failed \| In Progress |
| reason | String | Failure reason provided as an enum e.g. Delivered \| DestinationNotAllowed \| Inbound \| LandlineNotAllowed \| MessagePartCountExceeded \| MsisdnInvalid \| NetworkFailed \| OptedOut \| OutsideBusinessHours \| PartiallyDelivered \| senderIdInvalid \| SendingLimitExceeded \| WithinQuietHours |
| msisdn | String | The phone number that received the outbound message or the phone number that sent the inbound message. Must use international format e.g. 447xxxxxxxxx. This lets you filter for all messages from and to an MSISDN |
| destinationCode | String | Nullable. 2-letter ISO3166 destination code for the destination of the message e.g. Destination sent to/ or destination received from |
| originator | String | The "from" value for outbound messages or the "to" value for inbound messages. This lets you filter for all messages from and to an originator such as a VMN or Shortcode or senderId |
| requestName | String | Nullable. Optional name of the request |
| channel | String | Channel the message was sent via. Enum e.g. SMS |
| messageType | String | Enum e.g. Unknown \| MarketingAndResearch \| NotificationsAndReminders \| AuthenticationAndSecurity \| PaymentsAndCollections \| InternalOperations \| CustomerSupport \| Conversational |
| source | String | Which product area provided the message |
| startTime | dateTime | Filter messages where submittedAt is greater than or equal to startTime |
| endTime | dateTime | Filter messages where submittedAt is less than or equal to endTime |
| pageSize | Integer | Pagination required for the response. Allow 1-1000. Default = 1 |
| pageNo | Integer | Number of pages for the response. Allow 1+. Default = 1 |
| sortOrder | Query | Defines sorting order for the results. Enum e.g. Asc/ Desc. Default = Desc |
| sortBy | Query | Defines sorting requirements for the results Enum e.g. Status \| submittedAt \| lastupdatedTimestamp \| channel \| messageType \| source \| requestName. Default = submittedAt |
| retrieveMessageBody | Boolean | Provide if message body is required within the response. Default = TRUE |
| direction | Query | Enum e.g. Outbound/ Inbound |
