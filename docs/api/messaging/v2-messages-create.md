## API overview

This endpoint enables you to take your customers on a seamless messaging journey, foster a deeper connection with your brand, and gain valuable customer insights along the way. Whether you're sending to one recipient or multiple, you can do it all in a single request.

The documentation in this section contains the core reference information you will need to send an outbound message via our API, including required headers, code examples & error codes.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites in our Introduction documentation.

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required, or conditional, request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependant on the desired format of the message.

| Parameter | Type | Required or Conditional | Description |
| --- | --- | --- | --- |
| accountReference | String | Required | Your Spryng account reference - e.g. SPNL0000000 |
| channel | String | Required | The channel to be used for the message. Allowed options SMS |
| body | JSON object | Required | The content of the message being sent. It can contain 2 possible strings: either "text" or "templateId" provided in GUID format |
| body.text | String | Conditional | Required if not using "templateId".Text in the message body should be provided as a String. Variables can be provided using square brackets such as “variablename1” and “example2”. Only one of “text” or “templateId” should be provided within a request. If you would like to include a shortened URL within your message body embed shorten: http://example.com into your message "text" string. Note: this feature is not available during Trial |
| body.templateId | GUID | Conditional | The value of the template you wish to use in your message |
| from | String | Conditional | Required if no default senderId has beeen set. This is the originator to be used. This can be alphanumeric aka senderId or numeric. If numeric it must be a VMN or Shortcode that you have purchased. If alphanumeric then you may need to register the senderId in advance. You can set a default senderId in your Spryng portal account |
| recipients | JSON array | Conditional | Use recipients if you wish to send to a numbers which is not registered as a contact. Can contain an array of recipient objects between 1 and 50000. Either "recipients" or "addressbook" must be provided |
| addressBook | JSON object | Conditional | Required if not using "recipients". Use addressBook if you wish to send to existing contacts. If using addressBook addressBook.contacts & addressBook.contacts.id will be required. A max of 50000 contacts can be sent in a single request |
| addressBook.contacts | JSON array | Conditional | Required when using "addressBook". Can contain an array of contacts |
| addressBook.contacts.id | GUID | Conditional | Required when using "addressBook". The contactId of the contacts you wish to send your message to. A max limit of 10000 contactIds can be provided per request |

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| name | String | Optional friendly name for the request. Will be present message history export and can make some data analysis or grouping easier |
| characterSet | String | Allowed character sets are: Auto \| GSM \| Unicode. GSM uses a smaller character set which allows characters per message part to around 140. Unicode allows using of a large set of special characters and unicode emojis but reduces characters per message part to around 70. Auto will detect if unicode characters are used and default to GSM if not. If omitted |
| validity | Timestamp | Retry period of the message. If provided the validity must be more than 1 minute and less than 72 hours in the future. Default = 72 hours. e.g. 2025-07-19T09:07:12.190Z |
| messageType | String | Used to help reporting on certain message types. Enum e.g. MarketingAndResearch \| NotificationsAndReminders \| AuthenticationAndSecurity \| PaymentsAndCollections \| InternalOperations \| CustomerSupport \|Conversational |
| metaData | JSON object | Can contain "key": "value" pairs. These are saved with the message and will be returned when exporting the message history. This can make some data analysis easier |

In order to shorten a URL within a message, embed [shorten: http://example/longURL.com] into the request "body.text" property. The platform will then automatically convert your long URL into a shortened URL in format uk.endx.io/abcd123. These are unique per recipient.

        if (responseCode >= 200 && responseCode < 300) {
          try (var reader = new java.io.BufferedReader(
            new java.io.InputStreamReader(connection.getInputStream(), StandardCharsets.UTF_8))) {
              StringBuilder response = new StringBuilder();
              String line;

              while ((line = reader.readLine()) != null) {
                  response.append(line.trim());
              }
            }
        }
        else {
          try (var errorReader = new java.io.BufferedReader(new java.io.InputStreamReader(connection.getErrorStream(), StandardCharsets.UTF_8))) {
            StringBuilder errorResponse = new StringBuilder();
            String line;

            while ((line = errorReader.readLine()) != null) {
                errorResponse.append(line.trim());
            }

            System.err.println("Error Response: " + errorResponse.toString());
          } catch (Exception e) {
            System.err.println("Failed to read error response: " + e.getMessage());
          }
        }

        connection.disconnect();
    }
