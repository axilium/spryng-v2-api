# Messaging / Get by messageId

Source: <https://developer.spryng.nl/messaging/v2-messages-get-by-id>

## API overview

This endpoint returns all data for a single message. Including, but not limited to: delivery status, channel, message type, character count, account reference, message parts. This report can only be used for individual messages with a valid messageId.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/messages/{messageId}
```

**Method: GET**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Description |
| --- | --- |
| X-Api-Key | API Key value |
| AccountReference | String |

**Example request header:**

```
POST https://api.spryng.nl/v2/messages/{messageId}
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Required input parameters**

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

| Property | Type | Description |
| --- | --- | --- |
| messageId | String | The messageId of the request to be provided as a string in the path. The messageId can be found in the response from your v2/messages request |

                  response.append(line.trim());
              }
            }
        }
