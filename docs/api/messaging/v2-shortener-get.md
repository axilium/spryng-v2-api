## API overview

This endpoint allows you to retrieve data associated with a request sent using shorten parameter. Both parameters can be used when using POST v2/messages, v2/schedule or v2/throttle-schedule

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/url-shortener/visits
```

**Method: GET**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Description |
| --- | --- |
| X-Api-Key | API Key value for authorization |
| AcccountReference | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/url-shortener/visits
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Query parameters**

The below parameters are available as optional filters to your request. They should be provided as a query within the request path.

| Property | Type | Description |
| --- | --- | --- |
| pageSize | Integer | Pagination required for the response. Allow 1-1000. Default = 1 |
| pageNo | Integer | Number of pages for the response. Allow 1+. Default = 1 |
| sortOrder | Query | Defines sorting order for the results. Enum e.g. Asc \| Desc. Default = Desc |
| sortBy | Query | Defines sorting requirements for the results Enum e.g. RequestSubmittedAt \| RequestName. Default = submittedAt |
| startTime | dateTime | Filter messages where submittedAt is greater than or equal to startTime |
| endTime | dateTime | Filter messages where submittedAt is less than or equal to endTime |
