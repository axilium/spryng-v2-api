## API overview

This endpoint enables you to programmatically manage your opt outs to ensure that you respect customer preferences and comply with messaging regulations.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/optouts?Channel=String&Value=String
```

**Method: DELETE**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header**

```
DELETE https://api.spryng.nl/v2/optouts?Channel=String&Value=String
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Required input parameters**

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependant on the desired format of the message.

| Property | Type | Description |
| --- | --- | --- |
| Value | String | The MSISDN value which will remove the opt out for |
| Channel | String | The channel which will opted out for. Possible values: SMS |
