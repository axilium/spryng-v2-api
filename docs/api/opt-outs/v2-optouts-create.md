## API overview

This endpoint enables you to programmatically manage your contact lists to ensure that you respect customer preferences and comply with messaging regulations.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/optouts
```

**Method: POST**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| Content-Type | String | application/json |

**Example request header**

```
POST https://api.spryng.nl/v2/optouts
-H 'Api-Key: YOUR_API_KEY'
-H 'Content-Type: application/json'
```

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required, or conditional, request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Required or conditional | Description |
| --- | --- | --- | --- |
| accountReference | String | Required | Your Spryng account reference - e.g. SPNL0000000 |
| channel | String | Required | The channel to be used for the message. Enum e.g. SMS |
| value | String | Required | The customer value which is to be updated |

**Request body example**

```

    "accountReference": "SPNL0000000",
    "channel": "SMS",
    "value": "+447917810310"
}
```

        {
  "accountReference": "SPNLxxxxxx",
  "channel": "channel",
  "value": "value"
}""";

            byte[] input = body.getBytes(StandardCharsets.UTF_8);
            outputStream.write(input, 0, input.length);
        }
        catch (Exception e) {
            System.err.println("Failed due to error: " + e.getMessage());
        }
        
        int responseCode = connection.getResponseCode();

        if (responseCode >= 200 && responseCode < 300) {
          try (var reader = new java.io.BufferedReader(
            new java.io.InputStreamReader(connection.getInputStream(), StandardCharsets.UTF_8))) {
              StringBuilder response = new StringBuilder();
              String line;

              while ((line = reader.readLine()) != null) {
                  response.append(line.trim());
              }
            }
        }
        else {
          try (var errorReader = new java.io.BufferedReader(new java.io.InputStreamReader(connection.getErrorStream(), StandardCharsets.UTF_8))) {
            StringBuilder errorResponse = new StringBuilder();
            String line;

            while ((line = errorReader.readLine()) != null) {
                errorResponse.append(line.trim());
            }

            System.err.println("Error Response: " + errorResponse.toString());
          } catch (Exception e) {
            System.err.println("Failed to read error response: " + e.getMessage());
          }
        }

        connection.disconnect();
