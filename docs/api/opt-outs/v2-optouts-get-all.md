# Opt outs / Get all

## API overview

This endpoint enables you to programmatically manage your contact lists to ensure that you respect customer preferences and comply with messaging regulations.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/optouts
```

**Method: GET**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header**

```
POST https://api.spryng.nl/v2/optouts
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Optional input path parameters**

The below parameters are optional within the path, they are designed to provide you further capability to filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| Address | Query | The number MSISDN the opt out is associated |
| Channel | query | The channel to be used for the message request provided as a string e.g. SMS |
| StartTime | Query | Display messages starting from the specified date in ISO 8601 format (yyyy-MM-ddThh:mm:ssZ) |
| EndTime | Query | Display messages until the specified date in ISO 8601 format (yyyy-MM-ddThh:mm:ssZ) |
| SortBy | Query | Sort contacts into grouped data. Available values: Name \| createdAt |
| SortOrder | Query | Sets the sorting direction. Default= descending. Available values: Asc & Desc |
| OptOutMethod | Query | The way in which the opt out was received. Available values: Stop \| Manual. Stop has been received by a customer replying opt out. Manual has been added directly into the Connect platform. |
