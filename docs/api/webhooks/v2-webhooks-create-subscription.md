## API overview

This endpoint allows for the creation of a new webhook event subscription.

Webhooks are automated messages sent from our applications when something happens (an event occurs) and received to any valid public URL or application* included in your request. This event-triggered communication allows for near real-time data sharing, providing instant updates on message statuses and more. You must create a new webhook for each event you would like to subscribe to or receive updates on.

 A full list of available events is listed below. Please see the other documentation pages in the Webhooks section of this site for further information on possible webhook actions. Spryng has multiple options for additional security and webhook authentication. Please see our Webhook Authentication page for more information.

Note: *the receiving service must be a publicly accessible web page or web service which you host.

## Available events

There are multiple available events which can be subscribed to via our v2/webhooks. You can complete a GET v2/webhooks/events request to retrieve a full list of available events for your account, or refer to the below list. 

**Available webhook events**

| eventId | Description |
| --- | --- |
| sms-message-delivered | Receive updates for delivered messages. Updates will be received whenever the message-delivered event is triggered for requests associated to your account |
| sms-message-failed | Receive updates on failed messages. Updates will be received whenever the message-failed event is triggered for requests associated to your account |
| sms-message-received | Receive updates when an Inbound message has been received for any requests associated to your account |
| sms-inbound-opted-out | Receive updates when a customer has requested to opt out and stop receiving messages from your account. Updates will be received whenever the inbound-opted-out event is triggered for any request associated to your account |
