## API overview

This endpoint deletes **all** webhook subscriptions for an account. Only use this endpoint if you want to remove all updates being received for an account. This action is not revocable. If unintended, new webhook subscriptions would need to be created. To remove a specific event subscription, please use the Delete event endpoint.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/webhooks/subscriptions
```

**Method: DELETE**
