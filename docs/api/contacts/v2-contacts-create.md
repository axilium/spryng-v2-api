## API overview

This endpoint allows you to add a single contact in a single API call. This is the ideal tool for synchronising your contact list from another system, such as a CRM, an e-commerce platform, or a customer database, ensuring your contacts are always up-to-date.

The documentation in this section contains the core reference information you will need to create contacts via our API, including required headers, cURL sample & error codes.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/contacts/
```

**Method: POST**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| Content-Type | String | application/json |
| X-Api-Key | String | API Key value for authorization |

**Example request header:**

```
POST https://api.spryng.nl/v2/contacts
-H 'Api-Key: YOUR_API_KEY'
-H 'Content-Type: application/json'
```

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required, or conditional, request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Required or Conditional | Description |
| --- | --- | --- | --- |
| accountReference | String | Required | Your Spryng account reference - e.g. SPNL0000000 |
| contacts.firstName | String | Required | The first name of the contact. Max length 500 characters |
| contacts.lastName | String | Required | The last name of the contact. Max length 500 characters |
| contacts.addressType | JSON object | Conditional | The type of address to be stored e.g. MSISDN \| Email |
| contacts.addressValue | JSON value | Conditional | The email address or mobile number to be stored in the contact record |

            outputStream.write(input, 0, input.length);

            StringBuilder errorResponse = new StringBuilder();

          } catch (Exception e) {
            System.err.println("Failed to read error response: " + e.getMessage());
          }
