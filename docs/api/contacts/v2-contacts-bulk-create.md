## API overview

This endpoint allows you to add a list of new contacts in bulk with a single API request. 

Note: Existing contact records will not be updated when using this endpoint. To add and update existing records in the same call, please refer to the the Bulk update/create endpoint documentation.

The documentation in this section contains the core reference information you will need to create contacts via our API, including required headers, cURL sample & error codes.

Before you start using this endpoint, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

```
https://api.spryng.nl/v2/contacts/bulk
```

**Method: POST**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| Content-Type | String | application/json |
| X-Api-Key | String | API Key value for authorization |

**Example request header:**

```
POST https://api.spryng.nl/v2/contacts/bulk
-H 'Api-Key: YOUR_API_KEY'
-H 'Content-Type: application/json'
```

## Request body

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Required or Conditional | Description |
| --- | --- | --- | --- |
| accountReference | String | Required | Your Spryng account reference - e.g. SPNL0000000 |
| contacts.firstName | String | Required | The first name of the contact. Max length 500 characters |
| contacts.lastName | String | Required | The last name of the contact. Max length 500 characters |
| contacts.addressType | JSON object | Conditional | The type of address to be stored e.g. MSISDN \| Email |
| contacts.addressValue | JSON value | Conditional | The email address or mobile number to be stored |

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| contacts.quickName | String | The short name of the contact |
| contacts.optOutStatus | JSON Value | A binary value to determine if the user is opted out of marketing communications. Accepted values Subscribedor unsubscribed |
| contacts.contactMetadata | Object | Provided as an object e.g. “team” : “your data added here”. These are saved with the message and will be returned when exporting the message history. This can make some data analysis easier |
| contacts.groups | JSON array | Can be used to add the contact to group(s). If using this parameter a valid groupID must be provided |

            byte[] input = body.getBytes(StandardCharsets.UTF_8);
            outputStream.write(input, 0, input.length);

        catch (Exception e) {
            System.err.println("Failed due to error: " + e.getMessage());

        if (responseCode >= 200 && responseCode < 300) {

              StringBuilder response = new StringBuilder();
              String line;

              while ((line = reader.readLine()) != null) {
                  response.append(line.trim());
              }
            }
        }
        else {
          try (var errorReader = new java.io.BufferedReader(new java.io.InputStreamReader(connection.getErrorStream(), StandardCharsets.UTF_8))) {
            StringBuilder errorResponse = new StringBuilder();
            String line;

            while ((line = errorReader.readLine()) != null) {
                errorResponse.append(line.trim());
            }

            System.err.println("Error Response: " + errorResponse.toString());
          } catch (Exception e) {
            System.err.println("Failed to read error response: " + e.getMessage());
          }
        }

        connection.disconnect();
    }
