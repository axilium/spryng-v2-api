## API overview

This endpoint returns the balance of an parent account or sub account, only accounts linked with the credentials used can perform the request. Note this ony applies if you are a prepay customer, if you would like more information please speak with your account manager.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

**Endpoint URL**

```
https://api.spryng.nl/v2/balance
```

**Method: GET**

## Headers & parameters

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header**

```
GET https://api.spryng.nl/v2/balance
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```
