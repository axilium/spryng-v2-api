# Throttling / Get unsent messages

Source: <https://developer.spryng.nl/throttling/v2-scheduled-throttle-get-unsent>

## Api overview

This guide explains how to retrieve all unsent messages from a throttle Schedule, this will only return contacts when the throttled send has a status of partially completed, cancelled or failed campaigns.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites in our [Introduction documentation](https://developer.esendex.co.uk/home/esendex-uk-introduction).

## URL & method

```
https://api.spryng.nl/v2/throttle-schedule/{throttlescheduleid}/unsent
```

**Method: GET**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorisation |
| AccountReference | String | Your Esendex account reference - e.g. SPNL000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/throttle-schedule/{throttlescheduleid}/unsent
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

              StringBuilder response = new StringBuilder();

                  response.append(line.trim());
              }
            }
        }
        else {
          try (var errorReader = new java.io.BufferedReader(new java.io.InputStreamReader(connection.getErrorStream(), StandardCharsets.UTF_8))) {
            StringBuilder errorResponse = new StringBuilder();
            String line;
