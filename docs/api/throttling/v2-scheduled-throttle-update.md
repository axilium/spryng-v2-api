## Api overview

This guide explains how to edit a Scheduled Throttle, the ideal tool for controlling the rate at which your messages are sent during a specific, future time window.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites in our [Introduction documentation](https://developer.esendex.co.uk/home/esendex-uk-introduction).

## URL & method

```
https://api.spryng.nl/v2/throttle-schedule/{throttleScheduleId}
```

**Method: PATCH**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| Content-Type | String | application/json |
| X-Api-Key | String | API Key value for authorisation |
| AccountReference | String | Your Esendex account reference - e.g. SPNL000000 |

**Example request header:**

```
POST https://api.spryng.nl/v2/throttle-schedule
-H 'Api-Key: YOUR_API_KEY'
-H 'Content-Type: application/json'
-H 'AccountReference: SPNL000000'
```

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| throttleScheduleInformation.endDate | String | The end date of the throttle schedule e.g. “YYYY-MM-DD”. Required if configuring a periodic scheduled send |
| throttleScheduleInformation.timeSlotStart | String | The time the message should be sent provided in format HH:MM e.g. 11:47:25. The platform operates in UTC time zone exclusively. If you want to schedule a message to correspond to a different time zone |
| throttleScheduleInformation.timeSlotEnd | String | The end time of the throttle schedule e.g. “HH:MM:SS”. The platform operates in UTC time zone exclusively. If you want to schedule a message to correspond to a different time zone |
| throttleScheduleInformation.rateOfSend | String | The number of messages sent per hour. One of end date of the throttle or the rate of send must be provided. Minimum rate of send is 1 and the maximum 10 |
| throttleScheduleInformation.daysOfweek | JSON array | A list of days of the week throttled messages can be sent on. Possible values: Sunday \| Monday \| Tuesday \| Wednesday \| Thursday \| Friday \| Saturday |
| status | string | Update the status of the throttled schedule. Possible values Paused \| Active. |
| dispatch.name | String | Optional friendly name for the request. Will be present message history export and can make some data analysis or grouping easier |

**Request body example**

```
{
  "throttleScheduleInformation": {
```
