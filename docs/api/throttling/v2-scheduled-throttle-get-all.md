## Api overview

This guide explains how to retrieve all Throttle Schedules, add additional filtering on all the throttled schedules by adding a query parameter for FromStartDate, ToStartDate, FromCreatedDate, ToCreatedDate, Status, Msisdns and more

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites in our [Introduction documentation](https://developer.esendex.co.uk/home/esendex-uk-introduction).

## URL & method

```
https://api.spryng.nl/v2/throttle-schedule
```

**Method: GET**

## Required Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorisation |
| AccountReference | String | Your Esendex account reference - e.g. SPNL000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/throttle-schedule
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL000000'
```

**Query parameters**

The below parameters are available as optional filters to your request. They should be provided as a query within the request path.

| Property | Type | Description |
| --- | --- | --- |
| FromStartDate | String | Filter all the throttled schedules from a certain date. If both FromStartDate and ToStartDate are provided then throttled sends starting between the dates will be returned. Date must be provided in YYYY-MM-DD format |
| ToStartDate | String | Filter all throttled schedules until the start date provided. If both FromStartDate and ToStartDate are provided then throttled sends starting between the dates will be returned. Date must be provided in YYYY-MM-DD format |
| FromCreatedDate | String | Filter all throttled schedules from the created date provided. If both FromCreatedDate and ToCreatedDate are provided then throttled sends starting between the dates will be returned. Date must be provided in YYYY-MM-DD format |
| ToCreatedDate | String | Filter all throttled schedules until the created date provided. If both FromCreatedDate and ToCreatedDate are provided then throttled sends starting between the dates will be returned. Date must be provided in YYYY-MM-DD format |
| Status | String | Filter by the status of the throttled schedules. Available options are: Active \| Paused \| Cancelled \| Failed \| Completed \| PartiallyCompleted |
| msisdn | String | The phone number that received the outbound message. Must use international format e.g. 447xxxxxxxxx. This lets you filter for all messages to an MSISDN |
| PageSize | String | Pagination required for the response. Allow 1-1000. Default = 1 |
| PageNumber | String | Number of pages for the response. Allow 1+. Default = 1 |
| OrderDir | Query | Sets the sorting direction. Default = descending. Available values: Asc & Desc |
