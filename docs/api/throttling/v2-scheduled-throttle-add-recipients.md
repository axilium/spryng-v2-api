## Api overview

This guide explains how to add new participants to a throttle Schedule, the ideal tool for controlling the recipients on your throttled schedules. Recipients can be only be added when the status of the throttle schedule is active or paused.

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites in our [Introduction documentation](https://developer.esendex.co.uk/home/esendex-uk-introduction).

## URL & method

```
https://api.spryng.nl/v2/throttle-schedule{throttleScheduleId}/recipients
```

**Method: POST**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorisation |
| AccountReference | String | Your Esendex account reference - e.g. SPNL000000 |
| Content-Type | String | application/json |

**Example request header:**

```
POST https://api.spryng.nl/v2/throttle-schedule{throttleScheduleId}/recipients
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL000000'
-H 'Content-Type: application/json'
```

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required, or Conditional, Request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is Conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Required or Conditional | Description |
| --- | --- | --- | --- |
| msisdn | JSON array | Conditional | Either "recipients" or "contacts" must be provided. Can contain an array of recipient objects |
| contacts.contacts.id | GUID | Conditional | The contactId of the contacts you wish to send your message to |

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| recipients.metadata | JSON object | Can contain "key": "value" pairs. These are saved with the message and will be returned when exporting the message history. This can make some data analysis easier |
| recipients.variables | JSON object | Can contain "key": "value" pairs. These are saved with the message and will be returned when exporting the message history. This can make some data analysis easier |
