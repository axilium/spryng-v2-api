# Schedule / Get all

## API overview

This endpoint allows you to retrieve all message schedule data and scheduleIds. If you would like to retrieve the schedule data for a specific message schedule, please use GET v2/schedules/delayed/{scheduleId}

## URL & method

```
https://api.spryng.nl/v2/schedules/delayed
```

**Method: GET**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |

**Example request header:**

```
GET https://api.spryng.nl/v2/schedules/delayed
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
```

**Optional input path parameters**

The below parameters are optional within the path, they are designed to provide you further capability to filter your requests.

| Parameter | Type | Description |
| --- | --- | --- |
| DispatchName | Query | Filter by name |
| StartCreatedDateTime | String | Filter by created date/ time of the scheduled message. The time the message should be sent provided in ICT format YYYY-MM-DD:HH:MMZ e.g. 2025-03-05T11:47:25.723Z |
| StartSendDateTime | String | Filter by scheduled start send date/ time of the scheduled message. The time the message should be sent provided in ICT format YYYY-MM-DD:HH:MMZ e.g. 2025-03-05T11:47:25.723Z |
| EndSendDateTime | String | Sort groups. Filter by scheduled end send date/ time of the scheduled message. The time the message should be sent provided in ICT format format YYYY-MM-DD:HH:MMZ e.g. 2025-03-05T11:47:25.723Z |
| StatusFilter | Array | Filter by the status of the scheduled send. POssible values: Success \| Scheduled \| Canceled \| Failed \| Pending |
| Msisdns | Array | Filter by the recipients of the message |
| OrderBy | String | Order the results by Asending or Desending |
