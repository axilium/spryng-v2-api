## API overview

This endpoint allows you to update an existing message schedule. Any updates must be requested at least 5 minutes before the scheduled start time. Any requests within a 5 minute start time of the schedule will not take effect. 

Before you start your implementation, please check you have your Account, API Key and Base URL set up and have familiarised yourself with our implementation prerequisites.

## URL & method

```
https://api.spryng.nl/v2/schedules/delayed/{scheduleId}
```

**Method: PATCH**

## Headers

These parameters are mandatory to be provided in the header of your request. If not provided, or incorrect, your request will fail.

| Header | Type | Description |
| --- | --- | --- |
| X-Api-Key | String | API Key value for authorization |
| AccountReference | String | Your Spryng account reference - e.g. SPNL0000000 |
| Content-Type | String | application/json |

**Example request header:**

```
PATCH https://api.spryng.nl/v2/schedules/delayed/{scheduleId}
-H 'Api-Key: YOUR_API_KEY'
-H 'AccountReference: SPNL0000000'
-H 'Content-Type: application/json'
```

A valid scheduleId must be provided in the path of your request. If not provided, or invalid, then the request will fail. You can get a list of all the scheduleIds for your account using the GET v2/schedules/delayed endpoint

## Request body

You can use the cURL sample provided on the right hand side of this page to directly copy/paste into your chosen integration tool, using the below properties to modify your request as required for your business needs.

**Required request body parameters**

If a required parameter is not provided, or incorrect, the request will fail. If a parameter is conditional, it is only required for certain channels or is dependent on the desired format of the message.

| Parameter | Type | Description |
| --- | --- | --- |
| scheduleInformation.sendTime | String | The time the message will be sent provided in an ICT format YYYY-MM-DD:HH:MMZ. Z. The platform operates exclusively in UTC time zone. If you want to schedule a message to correspond to a different time zone please convert the desired send time from the destination time zone into UTC before inputting into your request. Any updates made to the send time of a schedule must be requested at least 5 minutes in advance of the scheduled send time. Any requests received within this window will fail |

**Optional request body parameters**

These parameters are not mandatory within the request body, they are designed to provide you further capability to customise or filter your requests.

| Paramter | Type | Description |
| --- | --- | --- |
| dispatch.name | String | Optional friendly name for the request. Will be present message history export and can make some data analysis or grouping easier |
